Paint Linestyle

Paint Filled Region and Masking Region boundary edges with project line styles

Overview

Paint Linestyle provides a compact palette of the project line styles and lets you either restyle every boundary edge of selected regions or paint individual region edges by clicking near them.

Apply to Selected Regions

Changes all boundary edges of every selected Filled Region or Masking Region to the chosen project line style.

Pick Edges

Lets you click near individual region edges in the active 2D view and changes only the selected edge, similar to editing a region boundary and changing that boundary line's style.

1. Search

Type one or more words to filter the project line-style list. Multiple search terms must all occur in the line-style name. When only one match remains, it is selected automatically.

2. Line-style preview

Each entry displays a graphic swatch using the project's line color and line weight, followed by the line-style name.

3. Actions

  • Apply to Selected Regions — restyles all edges of selected regions and finishes the command.
  • Pick Edges... — closes the palette temporarily and starts interactive edge painting.
  • Close — exits without applying another change.
Remembered palette: The window remembers its last position and size. During a single run, the last chosen line style is also retained when the palette reopens.

Workflow 1 — Apply to Selected Regions

  1. In Revit, select one or more Filled Regions and/or Masking Regions.
  2. Run Paint Linestyle.
  3. Search for and select the desired project line style.
  4. Click Apply to Selected Regions.
  5. Every boundary edge of each selected region is changed to that line style.
Select region(s)→Choose line style→Apply to Selected Regions→All edges restyled
Selection rule: Non-region elements in the Revit selection are ignored. If no Filled or Masking Regions are selected, the tool asks you to select regions first.

Workflow 2 — Pick Individual Edges

  1. Run the tool and choose the desired line style.
  2. Click Pick Edges....
  3. Click near a Filled Region or Masking Region boundary edge.
  4. Continue clicking additional edges to paint them with the same style.
  5. Press Esc to stop edge picking and return to the palette.
  6. Choose another style and repeat, or click Close.
Individual boundary edges may use different project line styles.
Picking tolerance: You do not have to click exactly on the sketch curve. The tool finds the nearest region boundary within a view-scale-dependent tolerance, approximately 3 mm on paper.

Supported Views and Regions

  • Regions: Filled Regions and Masking Regions.
  • Apply to Selected Regions: operates on selected region elements.
  • Pick Edges: requires a 2D view containing region sketch curves, such as a plan, reflected ceiling plan, section, elevation, detail, or drafting view.
  • Not supported for edge picking: 3D views and schedules.

How the Tool Changes the Boundary

The tool works directly with the curve elements that make up a region's boundary sketch. This permits individual edges to receive different line styles. For whole-region changes, it attempts to restyle every sketch edge and uses Revit's Filled Region line-style method only as a fallback when sketch curves cannot be found.

After changing a boundary, the tool briefly nudges the region and moves it back to force Revit to redraw the edges. This does not intentionally change the region's location.

Pinned or grouped regions: Revit may prevent the temporary refresh nudge. The line-style change can still succeed, but the new appearance may not display until Revit regenerates or otherwise refreshes the region.

Messages and Troubleshooting

“Select a line style first.”

Select a line style from the list before choosing an action.

“No region edge there — click closer to an edge”

The click was outside the current view-scale picking tolerance. Click closer to the visible region boundary.

“No region sketch curves were found in this view.”

The active view does not contain accessible Filled or Masking Region boundary curves.

“Revit would not let this edge's line style be changed through the API.”

Revit rejected the requested boundary edit for that curve. Try another region/edge or confirm that the element is editable in the current project context.

New style does not immediately appear

The region may be pinned, grouped, or otherwise unable to be nudged for the display refresh. Regenerating the view or editing/refreshing the region may reveal the changed style.

Usage Notes

  • The palette lists project line styles; the available choices therefore depend on the current Revit project.
  • The line-style search is case-insensitive and supports multiple space-separated search terms.
  • Apply to Selected Regions ends the command after applying the selected style.
  • Pick Edges is iterative: Esc returns to the palette so another style can be selected.
  • Closing the palette with Close or the window X ends the command.
  • The tool stores palette geometry in Paint_Region_Edges_palette.json under the user's application-data location.

Recommended Use

Use Apply to Selected Regions when a region should have a consistent perimeter style. Use Pick Edges when only certain sides need emphasis, suppression, or a different graphic convention.

Fast workflow: Search for a style → paint several edges → Esc → choose another style → continue painting.
